# Public distribution rules

- This is a clean publication workspace, not the personal working project. Read README.md and docs/privacy-and-publishing.md first.
- Do not copy private project memories, personal state, historical experiments, credentials or user data here.
- Personal records must not enter Git, test inputs, screenshots, commits, tags, issue text or workflow artifacts.
- Preserve third-party attribution. Use synthetic tests and isolated temporary databases only.
- Review every changed file and update the publication manifest intentionally. Never bypass a failed publication gate or regenerate the manifest automatically in CI.
- Never merge the old personal repository history. Historical data removal and remote changes require separate authorization.
