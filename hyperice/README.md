# Optional recovery interface

`app/static/hypervolt.html` is an experimental, user-configured device interface. No device MAC address, local network address, personal recovery history or downloaded videos are bundled. Confirm device compatibility yourself; operation is not guaranteed.

For remote-device access, configure your own host and a secure deployment. No existing personal scheduled tasks are installed or changed by this distribution. Optional notification links use `HEALTH_RECOVERY_PAGE_URL`; the default is loopback-only.

This interface is not a medical device or a personalized rehabilitation plan. Users with injury or rehabilitation needs should consult an appropriate healthcare professional before use.
